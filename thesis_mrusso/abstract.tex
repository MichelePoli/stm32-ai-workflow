\section{Abstract}

The deployment of Artificial Intelligence (AI) on resource-constrained embedded systems, often referred to as Edge AI, presents significant challenges due to limited memory, computational power, and energy budgets. The STM32 ecosystem provides powerful tools for this transition, such as STM32CubeMX and X-CUBE-AI, but orchestrating the entire Machine Learning Operations (MLOps) lifecycle—from firmware configuration to model optimization and deployment—remains a complex and manual task.

This thesis presents a scalable Agentic MLOps Orchestration Framework designed to automate and optimize the Edge AI development workflow on STM32 microcontrollers. Moving beyond local execution, the proposed architecture adopts a cloud-native approach deployed on a Kubernetes cluster to optimize resource utilization in research environments by decoupling the multi-agent orchestration logic (CPU-bound) from the Large Language Model inference engine (GPU-bound).

A key innovation of this work is the integration of NVIDIA Triton Inference Server, enabling a transition from monolithic containerized approaches—where single users often monopolize hardware resources—to a scalable architecture where high-performance LLMs are served as shared network resources. This design facilitates dynamic resource allocation, allowing multiple concurrent agentic workflows to compete efficiently for computational power without dedicated hardware reservation.

The framework manages seven specialized workflows, including automated firmware project generation, hardware-aware AI model analysis, and "neural network surgery," orchestrated via LangGraph and integrated into the Visual Studio Code IDE. Experimental validation compares three deployment scenarios: (1) local execution, (2) single-user monolithic containerization, and (3) the proposed scalable cluster architecture. Results demonstrate that the Triton-based solution significantly improves system throughput and hardware efficiency while providing reliable, optimized code generation for STM32 microcontrollers.
