\chapter{Results and discussion}

This chapter provides an evaluation of the framework through quantitative metrics and experimental scenarios. I first detail the production hardware infrastructure, which serves as the physical baseline for all subsequent tests. The analysis then focuses on the individual components, assessing the Web Search Agent's output quality using standardized evaluators for technical accuracy and relevancy. I also demonstrate the effectiveness of the autonomous fine-tuning system through a recorded end-to-end experiment. To conclude the assessment, I compare the automated workflow against traditional manual methods to quantify productivity improvements and report on the system's performance during multi-user concurrency tests.
