\section{Hardware Infrastructure}
\label{sec:used_hardware}

The production deployment runs on the \textbf{inNuCE Lab Heterogeneous Prototyping Platform (HPP)} \cite{innuce_website}. The cluster node used for this project is equipped with an \textbf{NVIDIA A40} GPU featuring \textbf{45~GB} of dedicated VRAM (46068~MiB), operating with driver version 580.95.05 and CUDA version 13.0. The GPU has a rated TDP of 300~W.

This capacity allows multiple heavyweight models (Mistral and \texttt{gpt-oss-20b}) to remain resident in VRAM simultaneously without triggering destructive load/unload cycles. Delegating LLM execution over the network to the HPP hardware frees the local workstation entirely for LangGraph orchestration logic and memory-intensive TensorFlow fine-tuning tasks.
