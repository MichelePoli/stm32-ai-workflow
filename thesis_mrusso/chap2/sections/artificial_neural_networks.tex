\section{Artificial Neural Networks}
The scientific quest to create machines capable of emulating human intelligence, formally recognized as \gls{ai}, began in the mid-20th century. While early efforts focused on symbolic AI—where expert knowledge was translated into rigid, rule-based logic—these systems often struggled with the ambiguity and complexity of real-world data environments \cite{Zhang2023AI70Years}. 

To overcome these limitations, the field shifted toward \gls{ml} in the 1980s. This paradigm emphasized data-driven learning, where algorithms improve their performance through experience rather than explicit programming \cite{Finley2024ClassicalML}. By the 2010s, the advent of \gls{dl} revolutionized the industry. By utilizing multi-layered neural networks, deep learning enabled the automatic extraction of hierarchical features from raw data, leading to unprecedented breakthroughs in computer vision and natural language processing \cite{Azizov2024DecadeDL}.

\subsection{The Perceptron: The Fundamental Building Block}
The structural foundation of modern neural networks is the perceptron, a computational model inspired by the biological neuron. A perceptron processes input signals by calculating a weighted sum and applying a step function to produce a binary classification \cite{Gabrie2023}:
\begin{equation}
y = \text{sign}(\mathbf{w}^\top \mathbf{x} + b)
\end{equation}
where $\mathbf{w}$ represents the weight vector, $\mathbf{x}$ the input, and $b$ the bias. While a single perceptron is limited to linearly separable tasks, stacking multiple neurons into layers—forming a Multilayer Perceptron (MLP)—allows for the approximation of highly non-linear functions, as illustrated in Fig. \ref{fig:perceptron} \cite{Schmid2025, NNWork2025}.

\subsection{Optimization and Training}
Training a neural network is essentially an optimization problem: finding the parameter set $\boldsymbol{\theta}$ that minimizes a cost function $J(\boldsymbol{\theta})$. For regression, a standard metric is the Mean Squared Error (MSE):
\begin{equation}
J(\boldsymbol{\theta}) = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
\end{equation}
where $y_i$ is the target and $\hat{y}_i$ is the model's prediction \cite{Gabrie2023}. 

Minimization is typically achieved via Gradient Descent, where weights are updated iteratively in the direction of the steepest descent:
\begin{equation}
\theta_{t+1} = \theta_t - \alpha \nabla J(\theta_t)
\end{equation}
The learning rate $\alpha$ is a critical hyperparameter that determines the step size. To handle large-scale datasets efficiently, researchers employ Stochastic Gradient Descent (SGD) and its variants, which estimate gradients using small batches of data. The efficiency of this process relies on the backpropagation algorithm (Fig. \ref{fig:back}), which leverages the chain rule of calculus to propagate errors from the output layer back to the input, enabling automated weight updates in complex computational graphs \cite{NNWork2025}.

\subsection{Specialized Architectures: CNNs and RNNs}
Different data types require specialized neural architectures to capture relevant patterns efficiently.

\textbf{Convolutional Neural Networks (CNNs):} Optimized for spatial data (e.g., images), CNNs use convolutional kernels to detect local features like edges and textures \cite{Li2020}. By sharing weights across the spatial domain, CNNs achieve translation invariance and significantly reduce the total number of parameters compared to fully connected layers. This is often followed by activation functions like ReLU and pooling layers to downsample feature maps (Fig. \ref{fig:conv}) \cite{OShea2015}.

    \centering

    \caption{Convolution operation within a neural network layer \cite{learnopencv_cnn}.}
    \label{fig:conv}
\end{figure}

\textbf{Recurrent Neural Networks (RNNs):} Tailored for sequential data, RNNs maintain a "hidden state" that preserves context from previous time steps \cite{Schmidt2019}. While basic RNNs suffer from vanishing gradients, more advanced variants like Long Short-Term Memory (LSTM) units use gating mechanisms (input, forget, and output gates) to manage long-term dependencies in sequences (Fig. \ref{fig:rnn}) \cite{Salehinejad2018, Lipton2015}.

\subsection{Model Decomposition and Layer-wise Manipulation}
For Edge AI deployment, traditional "black-box" training is often insufficient. Deploying models on microcontrollers requires a granular understanding of the network's architecture. \textit{Neural Network Surgery} or decomposition refers to the practice of isolating, modifying, or replacing specific layers within a pre-trained model. This technique is essential for domain adaptation—such as replacing the final classification head for a new task—and for hardware optimization, where specific non-linearities or layer types can be replaced with hardware-friendly equivalents (e.g., replacing complex activations with lookup tables or simpler functions). This thesis leverages agentic orchestration to automate these manipulations, ensuring that the model architecture remains compatible with the target STM32 hardware constraints throughout the MLOps lifecycle.
