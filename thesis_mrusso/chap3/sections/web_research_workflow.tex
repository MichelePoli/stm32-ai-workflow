\section{Web Research Workflow for Technical Guidance}
\label{sec:web_research}

Workflow 4 implements a RAG-improved web research system for gathering technical documentation, troubleshooting guides, and best practices from online sources. This workflow augments the embedded AI development process with real-time information retrieval.

\subsection{Query Generation and Iterative Refinement}

The workflow uses LLM-driven query generation to produce diverse, specific search queries:

\begin{lstlisting}[language=Python, caption={Multi-query generation for detailed coverage}]
# Generate 6 diverse search queries covering different aspects
queries = llm.generate_queries(user_question)
# Example: "STM32 X-CUBE-AI deployment guide"
#          "TensorFlow Lite quantization for embedded"
#          "STM32H7 neural network performance optimization"
\end{lstlisting}

Queries are then ranked by relevance using a second LLM call, prioritizing the most pertinent searches.

\subsection{Multi-Tool Web Search}

The system employs Agno's tool ecosystem to access multiple search backends. It primarily utilizes TavilyTools, a search engine fully optimized for LLM consumption that retrieves full content for up to five documents per query. To ensure detailed coverage, it uses GoogleSearchTools as a fallback for broader web queries, alongside DuckDuckGoTools as a privacy-focused alternative for redundancy.

Search results are parsed, deduplicated, and chunked into paragraph-level segments.

\subsection{Summarization and Quality Evaluation}

Retrieved content is synthesized into a coherent summary using an LLM through a structured, multi-stage process. 

First, an initial summary is generated from the first batch of search results. The system then enters a reflection phase to independently identify any remaining knowledge gaps within this current summary. Based on these gaps, it executes a follow-up search by generating new, highly targeted queries. 

Finally, it performs iterative extension, smoothly expanding the existing summary with the newly acquired information, a cycle that can repeat for up to three iterations to ensure maximum completeness.

After the final iteration, DeepEval metrics assess summary quality:

\begin{itemize}
  \item \textbf{Faithfulness}: Are claims grounded in retrieved documents? (Target: \textgreater 0.7)
  \item \textbf{Answer Relevancy}: Does summary address user question? (Target: \textgreater 0.7)
  \item \textbf{Contextual Relevancy}: Are retrieved documents relevant? (Target: \textgreater 0.7)
  \item \textbf{Hallucination}: Does summary contain fabricated information? (Target: \textless 0.2)
\end{itemize}

Results are presented to the user along with source citations, enabling verification of technical claims.
