\section{Used tools}
The development part of this work has been carried out using professional tools currently used in the field. In particular:
\begin{itemize}
    \item Firmware Development: uVision IDE from KEIL for BlueTile, STM32CubeIDE (based on Eclipse) from ST for SensorTile.box
    \item Client Development: PyCharm IDE from JetBrains
    \item Data Processing: MATLAB
    \item Version Control System: GIT
\end{itemize}
